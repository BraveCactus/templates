# AGENTS.md

## Цель
Перенос фотографий из исходной директории в целевую с группировкой по дате съёмки и созданием папок с обобщающими названиями.

## Пути
SOURCE_DIR="C:\Users\matve\Desktop\source"
TARGET_DIR="C:\Users\matve\Yandex.Disk-baranchugov.matvey\Memories\2026"

## Предварительные действия
1. Проверить существование SOURCE_DIR и TARGET_DIR.
2. Просканировать TARGET_DIR.
3. Если TARGET_DIR содержит папки, изучить структуру, формат дат, язык, разделители, регистр, длину и стиль названий.
4. Принять существующий стиль как обязательный.

## Обработка
1. Просканировать SOURCE_DIR.
2. Определить файлы изображений.
3. Для каждого изображения получить дату съёмки из EXIF DateTimeOriginal. При отсутствии использовать дату изменения файла.
4. Сгруппировать изображения по календарной дате.
5. Для каждой группы определить общее содержание изображений.
6. Сформировать название папки в стиле TARGET_DIR. При отсутствии стиля использовать YYYY-MM-DD_<краткое_описание>.
7. Создать папку в TARGET_DIR.
8. Переместить все изображения группы в созданную папку.
9. Сохранять исходные имена файлов. При конфликте добавить суффикс.
10. Перейти к следующей группе.

## Существующие папки
1. Если для даты уже есть папка в TARGET_DIR, использовать её.
2. Не создавать дубликат папки для той же даты.
3. Если существующая папка имеет название, соответствующее дате, переместить изображения в неё.

## Ограничения
1. Не удалять файлы.
2. Не изменять исходные файлы.
3. Не перемещать не изображения.
4. Не создавать пустые папки.
5. При невозможности определить дату пропустить файл и зафиксировать ошибку.
6. Не просматривай и не анализируй видео, просто добавляй их в папки с соотвествующими по дате фотографиями, если таковых нет, то пиши об этом пользователю

## Отчёт
1. Количество обработанных изображений.
2. Количество созданных папок.
3. Названия папок.
4. Количество ошибок.
5. Список пропущенных файлов.
